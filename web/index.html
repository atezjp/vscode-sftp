SFTP Japanese を
最短で使い始める

VS Code、Cursor、Antigravity で使える `SFTP Japanese` の導入ガイドです。 最初の設定ファイル作成から、ダウンロード開始、保存時アップロード、日常操作までを できるだけ迷わず進められるようにまとめています。

最短 5 ステップを見る Marketplace VSIX リリース
初回は、空のローカルフォルダを開いて SFTP: Download Project から始めると安全です。 既存ファイルの上書き事故を減らせます。

対応エディタ

  • VS Code
  • Cursor
  • Antigravity

設定ファイルの場所

  • .vscode/sftp.json

まず用意する情報

  • ホスト名または IP
  • 接続方式: sftp / ftp
  • ポート番号
  • ユーザー名
  • パスワードまたは秘密鍵
  • リモートフォルダ

最短 5 ステップ

はじめて使うときは、まずこの流れだけ押さえれば十分です。

1. ローカルフォルダを開く

  1. 同期したいプロジェクト用フォルダを開きます。
  2. リモートから先に取得したい場合は、空フォルダを使うのがおすすめです。

2. 設定ファイルを作る

  1. コマンドパレットを開きます。
  2. SFTP: Config を実行します。
  3. VS Code / Cursor / Antigravity で共通の .vscode/sftp.json が作成または表示されます。

3. 最小構成を入力する

最初は下のような基本設定で始められます。

{
  "name": "My Server",
  "host": "example.com",
  "protocol": "sftp",
  "port": 22,
  "username": "your-user",
  "remotePath": "/var/www/project",
  "uploadOnSave": false
}

4. まずは Download Project

空フォルダで始めたなら、SFTP: Download Project を最初に実行するのが安全です。 リモート側の内容をローカルに持ってきてから編集を始められます。

5. 編集してアップロードする

  • 1 ファイルだけ送るなら SFTP: Upload Active File
  • 自動同期したいなら uploadOnSave: true
  • 差分確認したいなら SFTP: Diff

パスワードは省略可能

password を設定ファイルに書かなくても使えます。 省略した場合は接続時に入力を求められます。秘密情報をファイルに残したくない場合はこちらがおすすめです。

設定ファイルの考え方

まずは「どのローカルフォルダを、どのリモートフォルダと対応させるか」を決めるだけで使い始められます。

最低限必要な項目

  • host: サーバー名または IP
  • protocol: sftp または ftp
  • port: たとえば SFTP は 22
  • username: 接続ユーザー名
  • remotePath: 同期したいリモートフォルダ

よくある追加設定

{
  "uploadOnSave": true,
  "ignore": [
    ".vscode",
    ".cursor",
    ".antigravity",
    ".git",
    "node_modules"
  ]
}

最初におすすめの使い方

慣れるまでは、手動操作と確認を優先すると事故を減らせます。

リモートの内容を先に持ってきたい

  • 空フォルダを開く
  • SFTP: Config で接続設定を書く
  • SFTP: Download Project を実行
  • ローカルで編集を開始

ローカルの完成物を先に送りたい

  • 既存プロジェクトフォルダを開く
  • SFTP: Config で接続設定を書く
  • SFTP: Diff で差分確認
  • SFTP: Upload Project を実行
本番環境に直接つなぐ場合は、いきなり uploadOnSave: true にせず、 最初は手動アップロードと差分確認から始めるのがおすすめです。

よく使うコマンド

最初の 1 週間でよく触るコマンドだけに絞っています。

コマンド 用途 最初に使うタイミング
SFTP: Config 設定ファイルを作成または開く 導入直後
SFTP: Download Project リモート全体をローカルへ取得 空フォルダから始めるとき
SFTP: Upload Project ローカル全体をリモートへ送信 ローカルが先に完成しているとき
SFTP: Upload Active File 今のファイルだけ送る 小さく確認したいとき
SFTP: Download Active File 今のファイルのリモート版を取得 上書き確認や復元時
SFTP: Diff ローカルとリモートの差分確認 本番反映前
SFTP: Sync Local -> Remote ローカル基準で同期 複数ファイルをまとめて反映したいとき
SFTP: Sync Remote -> Local リモート基準で同期 サーバー側変更を取り込みたいとき

Remote Explorer の使いどころ

サイドバーからリモートの状態を見ながら作業したい人向けです。

できること

  • リモートファイルを一覧表示
  • ファイル内容の確認
  • ローカルにダウンロードして編集
  • フォルダ単位のアップロード / ダウンロード
  • リモート上でファイル / フォルダ作成や削除

表示されない場合

エディタによってはサイドバー導線が見えづらいことがあります。 その場合でも、コマンドパレットから主要コマンドは実行できます。

困ったときの確認ポイント

まずは次の項目を順番に見ていくと原因を絞りやすいです。

接続できない

  • host, protocol, port, username が正しいか
  • remotePath が実在するか
  • パスワードまたは秘密鍵が正しいか
  • サーバー側で接続元 IP 制限がないか

設定ファイルが作られない

  • コマンドパレットから SFTP: Config を実行したか
  • ワークスペースとしてフォルダを開いているか
  • .vscode, .cursor, .antigravity のどこにできたか確認したか

同期結果が想定と違う

  • 初回は Diff で差分確認する
  • ignore の設定を見直す
  • 空フォルダから Download Project でやり直す

ログを見る

うまくいかないときは、出力パネルの SFTP ログを見るのが最短です。 接続エラーやパス不一致の情報が出ることがあります。
